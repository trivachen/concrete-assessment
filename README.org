* Concrete assessment

** Introduction

This is a repository, in which I am trying to predict the ~Concrete compressive strength~ field of ~Concrete Compressive Strength~ dataset, that it is available [[https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength][here]].

It has no practical meaning, except of showing off my skills.

** Setup

First and foremost, create ~data/~ folder and place there ~Concrete_Data.xls~. Then, you are almost ready to go. Just do the basics:

#+begin_src bash
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  python main.py
#+end_src

** Implementation

The whole point of this project is to find such ~w~, multiplying by which ~X~ will give the most close to ~y~ variable result. This is made through adjusting the ~w~ using MSE function.

** State

Right now, there is only one layer in ~w~ variable and, therefore, the prediction is not very precise (but, at least, it kinda works).
